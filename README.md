## 🎯 Projects Overview

### 📊 Project 1: EDA Retail Sales Analysis
**Location:** `project_1_eda_retail_sales/`

An exploratory data analysis (EDA) project focused on retail sales data with interactive Streamlit dashboard.

**Key Features:**
- Comprehensive data analysis and visualization
- Interactive Streamlit dashboard for data exploration
- Statistical insights and trend analysis
- Data preprocessing and cleaning
- Sample data generation for testing

**Tech Stack:** Python, Pandas, Matplotlib, Seaborn, Plotly, Streamlit

**Quick Start:**
```bash
cd project_1_eda_retail_sales
pip install -r requirements.txt
streamlit run dashboard.py
```

**Project Files:**
- `eda_retail_sales.py` - Main EDA analysis script
- `dashboard.py` - Interactive Streamlit dashboard
- `generate_sample_data.py` - Sample data generation
- `data/` - Data files
- `notebooks/` - Jupyter notebooks for analysis
- `visualizations/` - Generated visualization files
- `README.md` - Project-specific documentation

---

### 🔍 Project 2: Fraud Detection System
**Location:** `project_2_fraud_detection/`

**Key Features:**

**Tech Stack:** Python, Machine Learning, Streamlit, Power BI, Web Framework

## 🚀 Getting Started

### Prerequisites
- Python 3.8 or higher
- pip (Python package manager)

### Installation

1. **Clone the Repository**
```bash
git clone https://github.com/bishal531/OIBSIP.git
cd OIBSIP
```

2. **Choose a Project**

**For Retail Sales EDA (Project 1):**
```bash
cd project_1_eda_retail_sales
pip install -r requirements.txt
streamlit run dashboard.py
```

**For Fraud Detection (Project 2):**
```bash
cd project_2_fraud_detection
pip install -r requirements.txt
python main.py
```

3. **Refer to Project-Specific Documentation**

Each project folder contains its own detailed README with additional setup instructions and usage guidelines.
